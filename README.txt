ANIMATED SHRI BALAJI JYOTISH KENDRA WEBSITE
==========================================
This package includes:
- index.html with lightweight CSS animations and scroll reveal
- all 8 gemstone photos in the SAME root folder as index.html

To publish to your new GitHub repository:
1. Extract this ZIP on your phone/computer.
2. Upload/replace index.html and all 8 JPG files directly in the repository root.
3. Do NOT upload the ZIP as a single file and do NOT move photos into a different folder.
4. Commit changes. GitHub Pages is configured for main / (root), so wait a few minutes.
5. Open your repository's Pages URL and refresh.
